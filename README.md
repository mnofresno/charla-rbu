# charla-rbu

## Descripción

**charla-rbu** es una pequeña página web diseñada para compartir información con mis compañeros del curso de oratoria 2017. Este proyecto tiene como objetivo facilitar la comunicación y el intercambio de recursos entre los participantes del curso.

## Estructura del Proyecto

La página está basada en el template [TRANSIT](https://templated.co/transit), el cual está diseñado para ser simple y efectivo, permitiendo una fácil navegación y acceso a la información.

### Archivos del Proyecto

- **index.html**: Página principal de la web.
- **elements.html**: Contiene elementos de diseño reutilizables.
- **generic.html**: Plantilla genérica para el contenido.
- **css/**: Carpeta que contiene los archivos CSS para el estilo de la página.
- **js/**: Carpeta que incluye scripts JavaScript para la funcionalidad.
- **fonts/**: Contiene las fuentes utilizadas en la web.
- **images/**: Carpeta que alberga las imágenes utilizadas en el diseño.

## Instalación

Para utilizar este proyecto, simplemente clona el repositorio y abre el archivo `index.html` en tu navegador web:

```bash
git clone https://github.com/tu_usuario/charla-rbu.git
cd charla-rbu
open index.html
```

## Uso

Navega por la página para acceder a la información compartida. Puedes utilizar los enlaces y botones disponibles para explorar los diferentes recursos.
